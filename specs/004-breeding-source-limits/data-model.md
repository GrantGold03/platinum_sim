# Data Model: Breeding and Fossils Respect One-Time Choices (004)

Only changed or new fields are listed.

**Terms**: the spec's *choose-one group* is `exclusive_group`, and the option chosen within it
is `group_choice`. RUN-STATE's "one-time choice" means the same pair.

## Entry (availability ledger, `src/platsim/availability/sources.py`)

| Field | Change | Values |
|---|---|---|
| `exclusive_group` | existing; new value | `"starter"` (unchanged), `"trainer_id_parity"` (new: fossil revivals) |
| `group_choice` | **new** | Starter gift: the species constant (`SPECIES_CHIMCHAR`). Fossil revival: `"odd"` / `"even"`. `None` when no group. |
| `quantity` | changed for fossil revivals | `"unlimited"` when the fossil item is diggable without limit before the Champion; otherwise the item's copy count |

- `group_choice` for a fossil comes from the extracted mining weights. It is the one parity whose
  pre-National-Dex weight is non-zero. A fossil with both parities non-zero has no group.
- `availability.json` is regenerated by `platsim extract`. `extract --check` covers the new field.
  `manifest.json` hashes change.

## SourceOption (`src/platsim/legality/movesources.py`)

| Field | Change |
|---|---|
| `group_choice: str \| None` | **new**. Copied from the Entry. Evolutions keep it, as they keep `exclusive_group`. |
| `exclusive_group` on breed options | inherited (see rule B1); today it is always `None` |
| `consumes` on fossil revivals | adds `(fossil item, 1)` per revival |
| `detail` on breed options | names the parent's source, for example "Day Care egg from your starter Chimchar" or "Day Care egg from a revived Skull Fossil (odd Trainer ID)" |

### Rules

- **B1 (inheritance)**. A breed option for egg species E has `(exclusive_group, group_choice)`
  = (g, c) when every qualifying mother of E has only non-breed pre-Champion sources in group g,
  all with choice c. Otherwise it gets `(None, None)`.
- **B2 (partner)**. A breed option exists only if `compatible_father(mothers, led)` finds a
  father, or Ditto is obtainable (research R4).
- **B3 (one-time female)**. When a mother's only sources have a fixed personality or gender
  that cannot be female, that mother does not count. No current data triggers this (research
  R3). A fixture covers it.

## Team-level group rule (validator, optimizer, web)

- For each group g, collect the `group_choice` of every member whose chosen or possible source
  is in g.
- **Valid** when at most one distinct choice is used.
- **Per-option quantity** still applies. Example: the starter gift has `quantity=1`, so two
  members that both use the gift fail. A gift plus a bred copy passes.

## Ledger view

- `Ledger.item_copies("ITEM_SKULL_FOSSIL")` is already `"unlimited"` before the Champion (odd TID
  underground entry). No change.
- Post-game options do not lift the parity split: the decomp's National Dex weights keep the
  same zero.
