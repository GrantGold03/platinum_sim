# Implementation Plan: Breeding and Fossils Respect One-Time Choices

**Branch**: `004-breeding-source-limits` | **Date**: 2026-10-13 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/004-breeding-source-limits/spec.md`. Fossils were
added to the scope on 2026-10-13 by user decision (research R5).

## Summary

The engine accepts teams that one cartridge cannot produce. There are two causes:

- **Breed options ignore the choice behind their parent.** Day-Care eggs have no group, so all
  three starter lines are usable at once.
- **Fossil revivals ignore the Trainer ID.** Skull Fossils (Cranidos) are dug only with an odd
  Trainer ID and Armor Fossils (Shieldon) only with an even one. Each revival is also capped at
  one copy, although fossils can be dug again and again.

**Approach**:
- Keep `exclusive_group` and add a `group_choice` key.
  - Starter gifts carry their species as the choice. Fossil revivals carry `odd`/`even`, parsed
    from the mining weights.
  - Breed options inherit (group, choice) from mothers whose only sources are in that group.
- The team rule becomes "at most one choice per group". The per-option quantity check now also
  applies to grouped options.
- One shared conflict check refuses mixed teams in the optimizer and the web before a run. The
  validator checks the declared sources on its own.
- Breeding also requires a compatible father, or Ditto. This reuses the egg-move father search.
- Breed text names the parent's source.

**Expected result**: species-only teams of six distinct species go from 56,574,476,596 to
55,192,424,630. The 188 allowed species are unchanged.

## Risks

- **Fixtures with source text.** Fixtures that hold "Day Care egg (mother: ...)" text will
  change. This affects `tests/fixtures/web_final_defaults/result.{json,csv}` and the rerender
  tests. These fixtures are inputs (old runs), so only the newly generated text changes. Check
  each failing test for that before editing a fixture.
- **Greedy `realize` with groups.** The conflict check runs first, so a group dead-end in
  `realize` is not expected. A `realize` refusal on a team that passed the conflict check would
  be a bug, and the test matrix covers it.
- **Ledger build time.** Each test module pays about 35 s for its own ledger. New tests use the
  session `ledger` fixture from `tests/conftest.py`.
